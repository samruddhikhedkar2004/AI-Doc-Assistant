# 📄 AI Document Assistant
An AI-powered Document Assistant that allows users to upload PDF files and ask questions or generate summaries using Generative AI.

---

🚀 Project Overview

This application uses AWS Bedrock (Nova Lite) to understand document content and provide intelligent responses. It enables users to interact with documents in a conversational way instead of manually reading them.

---

## ✨ Features

- 📄 Upload PDF documents  
- 🤖 Ask questions about the document  
- 📝 Generate document summaries  
- ⚡ Fast AI responses using AWS Bedrock  
- 🎯 Clean and user-friendly interface  

---

## 🧠 Tech Stack

- Python  
- Streamlit  
- AWS Bedrock (Nova Lite)  
- boto3  
- PyPDF  

---

## ⚙️ How It Works
```
User uploads PDF
↓
Text extracted using PyPDF
↓
Prompt created (Document + Question)
↓
Sent to AWS Bedrock (Nova Lite)
↓
AI generates response
↓
Displayed in Streamlit UI
```
